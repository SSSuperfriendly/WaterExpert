# 科学因果机理框架（显式机理约束版，2026-04-12）

## 1. 文档目的

本文件解释了 `MSCIM + CMFBE-ST-GCN` 原型构建中，使用了哪些指导模型的科学因果逻辑，并把 `CMFBE-ST-GCN` 从“机理启发”推进到“显式科学分解的机理约束 ”。

---

## 2. 科学因果逻辑

### 2.1 总体逻辑

当前把“清澈度/浊度变化”拆成一条日尺度的因果链：

`外源输入 + 水动力扰动 + 潮汐滞留 + 生态增殖 - 沉降 - 冲刷外输 - 自净`  
`=> 日尺度 log_turbidity 变化`  
`=> clearness proxy 变化`

换成更细的过程层，就是：

1. `降雨/径流` 增加泥沙和污染物输入
2. `流量、水位、风浪` 决定床面剪切和再悬浮强度
3. `感潮回流/潮汐泵吸` 决定局地滞留和再输运
4. `营养盐 + 温度 + 光照 + 适中流速` 决定藻类增殖源项
5. `Krone 型沉降 + 冲刷外输 + 溶氧相关自净` 决定汇项
6. 源项减汇项之后，形成次日浊度变化

### 2.2 六条主因果链

#### 链 1：降雨-径流-泥沙脉冲链

`precipitation_3d / runoff_sediment_pulse / huangdu_flow_m3s_abs`
`-> runoff_source`
`-> log_turbidity 上升`

解释：

- 强降雨带来面源径流和泥沙脉冲
- 黄渡流量作为辅助来水输入信号
- 该链主要表达“外源输入”

#### 链 2：流速-剪切-再悬浮链

`songpu_flow_m3s_abs + huangdu_flow_m3s_abs + songpu_water_level_m`
`-> velocity_proxy`
`-> bed_shear_proxy`
`-> erosion_source`
`-> log_turbidity 上升`

解释：

- 水动力增强先提高流速代理
- 流速、风速和水位突变共同抬升床面剪切代理
- 超过临界阈值后触发再悬浮

#### 链 3：感潮滞留-潮汐泵吸链

`songpu_tidal_pumping_proxy + songpu_flow_level_coupling`
`-> tidal_source`
`-> log_turbidity 上升`

解释：

- 感潮河段中，回流、往复输运和局地滞留会增强浑浊物质保留
- 该链主要表达“不是新输入，而是再输运和再滞留”

#### 链 4：营养盐-温度-光照-流速生态链

`tn + nh3_n + tp + water_temp + dayofyear_sin + velocity_proxy`
`-> phytoplankton_source`
`-> log_turbidity 上升 / 清澈度下降`

解释：

- 本轮不直接预测藻密度，而是用一个生态增殖源项表达“藻类导致的附加浑浊”
- 采用温度限制、光照季节代理、营养盐限制和流速抑制共同控制

#### 链 5：Krone 型沉降-絮凝链

`bed_shear_proxy + conductivity + settling_index`
`-> krone_deposition_sink`
`-> log_turbidity 下降`

解释：

- 低剪切更有利于沉降
- 电导率作为絮凝代理
- `settling_index` 作为沉降有利条件代理

#### 链 6：冲刷外输-自净链

`velocity_proxy + songpu_flushing_potential`
`-> flushing_sink`
`-> log_turbidity 下降`

`dissolved_oxygen + self_purification_index`
`-> purification_sink`
`-> log_turbidity 下降`

解释：

- 高通量时，一部分浑浊物会被冲刷外输
- 同时 DO 和自净指数反映一定程度的恢复与净化能力

## 3. 落地到代码中的显式机理公式



### 3.1 速度代理

```text
u* = [a_q log(1 + Q_songpu) + a_h log(1 + Q_huangdu)] / [1 + a_d log(1 + H_songpu)]
```

含义：

- 用松浦大桥和黄渡流量构造日尺度速度代理
- 用松浦水位代理有效过水深度/断面效应

### 3.2 剪切代理

```text
tau* = a_tau u*^2 + a_w log(1 + wind_speed) + a_hs log(1 + |dH_songpu/dt|)
```

含义：

- 流速平方近似床面剪切趋势
- 风浪扰动和水位突变作为附加剪切来源

### 3.3 外源输入源项

```text
R_runoff = k_r [log(1 + runoff_sediment_pulse)
              + 0.35 log(1 + precipitation_3d)
              + 0.25 log(1 + Q_huangdu)]
```

### 3.4 再悬浮源项

```text
R_erosion = k_e softplus(tau* - tau_ce) (1 + 0.5 reverse + 0.25 rise)
```

说明：

- 这里用 `softplus` 代替硬阈值 `relu`，保证阈值可学习
- `reverse` 和 `rise` 分别来自反向流和上涨流标记

### 3.5 潮汐滞留源项

```text
R_tide = k_t [log(1 + tidal_pumping) + 0.3 log(1 + |flow_level_coupling|)]
```

### 3.6 生态增殖源项

```text
R_bloom = k_b f_T(T) f_I(light) min(f_N(N), f_P(P)) f_v(u*)
```

其中：

```text
f_T(T) = exp(-((T - T_opt) / T_width)^2)
f_I(light) = sigmoid(k_L (light_proxy - L0))
f_N(N) = N / (N + K_N)
f_P(P) = P / (P + K_P)
f_v(u*) = sigmoid(4 (u_crit - u*) / w_v)
```

解释：

- 温度项参考藻类温度适生窗
- 光照项目前用季节正弦项作日尺度代理
- 营养盐采用 `Monod` 型限制
- 流速项表达“流速过大时藻类增长受抑制”

### 3.7 Krone 型沉降汇项

```text
S_dep = k_d A_sed sigmoid(4 (tau_cd - tau*) / w_v) (1 + beta_floc) (1 + 0.25 log(1 + settling_index))
```

其中：

```text
A_sed = log(1 + T_t) / [1 + log(1 + T_t)]
beta_floc = beta_f tanh(log(1 + conductivity) / 5)
```

解释：

- `A_sed` 表示当前仍可沉降的“有效悬浮物份额”
- 用平滑 `sigmoid` 逼近 Krone 型“低剪切易沉降”的逻辑
- 电导率用于近似絮凝增强

### 3.8 冲刷外输汇项

```text
S_flush = k_f A_sed u* log(1 + flushing_potential)
```

### 3.9 自净汇项

```text
S_pur = k_p A_sed f_DO(DO) log(1 + self_purification_index)
```

其中：

```text
f_DO(DO) = sigmoid(k_DO (DO - DO_mid))
```

### 3.10 日尺度机理平衡方程

```text
log(1 + T_{t+1})
= clamp(
    log(1 + T_t)
    + R_runoff + R_erosion + R_tide + R_bloom
    - S_dep - S_flush - S_pur,
    0
  )
```

最终：

```text
clearness_{t+1}
= 1 - (log(1 + T_{t+1}) - log_turbidity_min) / (log_turbidity_max - log_turbidity_min)
```

## 4. 公式分别用了哪些现有数据

| 机理项 | 主要变量 | 当前数据是否具备 |
|---|---|---|
| 速度代理 | `songpu_flow_m3s_abs`, `huangdu_flow_m3s_abs`, `songpu_water_level_m` | 已具备 |
| 剪切代理 | `wind_speed`, `songpu_water_level_m_1d_diff` | 已具备 |
| 外源泥沙输入 | `runoff_sediment_pulse`, `precipitation_3d` | 已具备 |
| 再悬浮 | `songpu_flow_m3s_reverse_flag`, `songpu_flow_rise_flag` | 已具备 |
| 潮汐滞留 | `songpu_tidal_pumping_proxy`, `songpu_flow_level_coupling` | 已具备 |
| 生态增殖 | `water_temp`, `tn`, `nh3_n`, `tp`, `dayofyear_sin` | 基本具备，但缺真实光照和藻类标签 |
| 沉降絮凝 | `conductivity`, `settling_index` | 已具备代理 |
| 冲刷外输 | `songpu_flushing_potential` | 已具备代理 |
| 自净 | `dissolved_oxygen`, `self_purification_index` | 已具备代理 |

当前最缺的仍然是：

- 实际断面/流速场
- 底泥粒径和临界剪切应力
- 真实透明度 / Secchi 深度
- `Chl-a`、藻密度、辐射/光照
- 工程调度与治理事件数据
