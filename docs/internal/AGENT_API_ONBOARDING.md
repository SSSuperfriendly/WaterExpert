## 二、优先需要贵方做的事（P0）

### 1. 确认服务正在运行、端口与路径正确

请在**服务器本机**执行，并把输出贴回：

```bash
# 确认服务进程在跑、端口正确
curl -sS http://127.0.0.1:8000/api/health
echo
curl -sS http://127.0.0.1:8000/api/scenarios
```

- 如果 `/api/health` 返回类似 `{"status":"healthy","agents":{...}}`，说明服务正常。
- 请同时确认公网入口是否就是 `http://219.228.144.101:8000/api`（前缀 `/api` 是否正确）。

### 2. 网络放行（防火墙 / 安全组 / IP 白名单）

目前我方网络完全无法连接贵方服务器。请在贵方服务器/安全组确认：

- 端口 `8000` 是否对外开放（公网可达）；
- 是否配置了 IP 白名单 —— 若有，请将**我方平台部署服务器的公网 IP** 加入白名单，
  并告知白名单的配置方式（以便后续变更）。

### 3. 提供 OpenAPI 接口文档（最重要，替代回忆）

贵方若忘记当初实现细节，无需回忆 —— 请直接导出 FastAPI 自带的接口定义：

```bash

```

> 该文件包含全部端点、请求/响应结构、字段与枚举，是我方核对接口的唯一权威依据。
> 若文件较大，可直接把 `openapi.json` 文件发给我们。

## 三、需要贵方确认的合同细节（P1）

### 4. 场景编码

文档中：

- 场景列表返回 `{"code": "S1", "name": "External Input Type"}`；
- 但生成策略的示例请求使用 `"scenario": "s1_external_input"`。

请确认 `/strategy` 接口实际接受哪种写法（`S1` 还是 `s1_external_input`，或两者皆可）。
如果两种都不对，请给出正确的场景编码取值。

### 5. 任务状态枚举

文档只提到 `queued / running / completed / failed`。请确认是否还有其他状态
（例如 `pending`、`success`），以及各状态的确切字符串。

### 6. 鉴权方式

文档提到"可选配置 API Key 或 JWT 认证"。请确认部署版本是否已启用鉴权：

- 未启用 → 无需处理，我方直接调用；
- 已启用 → 请提供认证方式与密钥（Key / Token / 获取方法）。

## 四、功能确认（P2）

### 7. 是否提供"问答/对话"能力

我方页面的产品定位是"应答"：用户提问、系统回答。贵方模型栈包含
`AquaTurbGPT` 与 `KnowledgeBase` 两个问答智能体，但 `INTEGRATION_GUIDE.md`
中**未公开任何问答端点**（只有策略生成）。

请确认：

- 是否存在问答/对话接口（如 `/api/ask`、`/api/chat`、`/api/qa` 等）；
- 若有，请补充该接口的请求/响应文档（或一并提供 `openapi.json` 即可）。

### 8. 部署版本信息

为便于以后升级对齐，请提供：

- 部署的服务对应哪个代码仓库、哪个 commit（或该服务的 README / 部署说明）；
- 当前部署的模型版本号（若有）。

## 五、建议的验证命令（可复制执行）

贵方确认完成后，可直接在本机执行以下命令自测并贴回输出：

```bash
# 1) 健康检查
curl -sS http://127.0.0.1:8000/api/health

# 2) 场景列表
curl -sS http://127.0.0.1:8000/api/scenarios

# 3) 生成策略（文档示例，按第 4 条确认的 scenario 取值替换）
curl -sS -X POST http://127.0.0.1:8000/api/strategy \
  -H "Content-Type: application/json" \
  -d '{"scenario":"s1_external_input","state":{"date":"2025-10-31","turbidity":25.5,"flow_rate":28.5},"episodes":1,"backend":"api"}'

# 4) 查询策略结果（把 <job_id> 换成第 3 步返回的 job_id）
curl -sS http://127.0.0.1:8000/api/strategy/<job_id>

# 5) OpenAPI 接口文档
curl -sS http://219.228.144.101:8000/openapi.json
```
